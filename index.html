      高德地图 Key 设置

      本应用地图数据来自高德地图，需要你自己的免费 Key。
      1. 打开 lbs.amap.com 注册并登录
      2. 控制台 → 应用管理 → 创建应用 → 添加 Key，服务平台选「Web端(JS API)」
      3. 把 Key 粘贴到下面，保存即可。Key 只存在你手机本地。

      不想申请 Key？直接关闭本窗口也能用：默认进入「免 Key 模式」，点按钮会在你手机地图里搜索，无需任何配置。填了 Key 则升级为内嵌地图（页面内直接看站点列表与画线）。

      使用说明

      • 定位：点底部「定位」获取你当前位置（需允许浏览器定位权限，且页面为 https）。

      • 附近：选公交站 / 地铁站 / 公共卫生间，自动列出 2 公里内点位，点「导航」调起高德前往。

      • 路线：输入目的地，自动用当前位置做起点，规划全国公交/地铁路线。

      • 查线：输入线路名（如「地铁1号线」「1路」），显示该线路全程站点与走向。

      • 关于数据：站点、路线、公厕均来自地图实时数据，需要联网；App 界面本身可离线打开。

      • 两种模式：没填高德 Key 时是「免 Key 模式」——点按钮跳到你选的地图 App 里、按当前位置搜索；没装高德也能用，切到百度/腾讯地图即可。填了 Key 则在页面内直接显示附近列表并可画线导航。

      • 安装到手机：浏览器菜单 → 「添加到主屏幕」，即可像 App 一样放在桌面使用。
