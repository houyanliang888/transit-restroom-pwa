# 出行助手 · 附近公厕与乘车导航

一个**手机可安装的 PWA 小工具**，专为「到了陌生城市出差 / 旅游」设计：

- 🚻 **找附近公共卫生间**：自动定位后，列出周边公厕，带距离、可一键导航
- 🚌 **找附近公交站 / 🚇 地铁站**：列出周边站点与距离
- 🚌 **乘车路线规划**：输入目的地，自动以当前位置为起点规划公交 / 地铁换乘方案
- 🚉 **查线路全程站点**：输入「地铁1号线」「1路」，显示该线路所有站点与走向

## 两种模式（自动切换）

| 模式 | 条件 | 体验 |
|---|---|---|
| **内嵌（推荐）** | 填了高德免费 Key | 本页面内直接显示附近列表 + 距离 + 导航 + 画线，最实用 |
| **临时** | 没填 Key | 零注册零配置，点按钮跳到你手机地图 App 按当前位置搜索 |

## 申请高德免费 Key（个人 0 元，几分钟）

1. 打开 https://lbs.amap.com/ ，用手机号注册
2. 做一下「个人开发者认证」（支付宝扫码，0 元）
3. 控制台 → 创建应用 → 应用类型选「**Web端(JS API)**」
4. 应用里「添加 Key」，服务平台选「**Web端(JS API)**」，提交即得
5. 打开本工具右上角 ⚙，把 Key 粘贴保存，刷新即升级为内嵌模式

> 个人开发者额度：周边搜索 100 次/日、路径规划 5000 次/日，个人与小范围推广够用。
